课程简介

欢迎来到高级机器学习（Advanced Machine Learning）课程网站。

高级机器学习（Advanced Machine Learning）在机器学习基础课程的基础上进行进一步深入的讲解，课程培养目标是使学生进一步掌握机器学习高阶话题，算法、模型，并且具备必要的技术运用技能，以及前沿文献阅读能力。在此过程中，将培养学生的知识运用能力、问题解决能力、技术创新能力、以及科研探索精神。

课程名称：高级机器学习

英文名称：Advanced Machine Learning
